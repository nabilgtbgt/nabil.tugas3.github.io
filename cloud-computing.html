Pengertian Cloud Computing

Dengan cloud computing,penggunaan tidak harus menympan seluruh data dan menjalankan seluruh aplikasi hanya pada komputer pribadi Data dan sumber daya komputer dapat disediakan melalui internet,sehingga pengguna dapat mengaksesnya dari berbagai perngkat selama terhubung ke jaringan


contoh layanan Cloud Computing yang sering di gunakan dalam kehidupan sehari-hari adalah Google Drive,Google docs,Microsoft OneDrive dan DropBox. layanan tersebut memungkinkan pennguna untuk menyimpan,mengelola,dan mengakses datasecara online tanpa harus bergantung sepenuhnya pada penymipanan komputer

Manfaat Cloud Computing

Cloud Computing memungkinkan pengguna untukmengakses data dari berbagai perangkat selama memiliki koneksi internet


teknologi ini juga memudahkan pengguna dalam berbagi file dan melakukan secarakolaboratif
